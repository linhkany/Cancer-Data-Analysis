# SQL

## SELECT

SELECT *
FROM patients;

Sélectionner toutes les colonnes.

## WHERE

SELECT *
FROM patients
WHERE age > 40;

Filtrer les données.

## ORDER BY

SELECT *
FROM patients
ORDER BY age;

Trier les données.

## GROUP BY

SELECT diagnostic, COUNT(*)
FROM patients
GROUP BY diagnostic;

Regrouper les données.

## JOIN

Permet de relier plusieurs tables.

## INSERT

Ajouter des données.

## UPDATE

Modifier des données.

## DELETE
