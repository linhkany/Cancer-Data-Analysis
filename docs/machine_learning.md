# Machine Learning

## Définition

Le Machine Learning est une branche de l'intelligence artificielle qui permet à un ordinateur d'apprendre automatiquement à partir de données afin d'effectuer des prédictions ou des classifications.

---

## Modèle

Un modèle est un programme qui apprend une règle à partir d'exemples.

---

## Features

Les features sont les variables explicatives utilisées pour entraîner le modèle.

Exemples :

- mean radius
- mean texture
- mean area
- ...

---

## Target

La target est la variable que le modèle doit prédire.

Dans ce projet :

- 0 = Tumeur maligne
- 1 = Tumeur bénigne

---

## Jeu d'entraînement

Le jeu d'entraînement (Training Set) est utilisé pour apprendre au modèle à reconnaître des relations entre les variables.

---

## Jeu de test

Le jeu de test (Test Set) permet de vérifier si le modèle est capable de prédire correctement des données qu'il n'a jamais vues.

---

## Standardisation

La standardisation consiste à mettre toutes les variables sur une échelle comparable afin d'améliorer les performances de certains modèles.

---

## Logistic Regression

La régression logistique est un modèle de Machine Learning utilisé pour résoudre des problèmes de classification.

---

## Accuracy

L'accuracy représente le pourcentage de bonnes prédictions réalisées par le modèle.

---

## Confusion Matrix

La matrice de confusion résume les prédictions correctes et les erreurs du modèle.

Elle permet de savoir quelles classes sont les plus difficiles à prédire.

---

## Classification Report

Le Classification Report fournit plusieurs indicateurs :

- Precision
- Recall
- F1-score
- Support

Ces métriques permettent d'évaluer les performances du modèle de manière plus détaillée que l'accuracy seule.
